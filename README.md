# Anime Fan Page 🎨✨

A simple fan page built with **HTML + CSS** showcasing favorite anime characters and themes.

---

## 🚀 Features
- Clean and responsive layout
- Anime character showcase section
- Custom CSS styling with colors and effects
- Easy to expand with new characters or series

---

## 📂 Project Structure
- `index.html` → Main page
- `style.css` → Custom styles
- `images/` → Anime images and assets
